# وبلاگ متریال (PHP + SQLite)

اجرای محلی:
    php -S localhost:8000

- سایت: http://localhost:8000/
- مدیریت: http://localhost:8000/admin/  (نام کاربری: admin / رمز: admin123 — بعد از ورود حتماً تغییر دهید)
- پایگاه داده در اولین بازدید خودکار ساخته می‌شود: data/blog.sqlite
- روی Apache فایل‌های .htaccess دسترسی به data/ و includes/ را می‌بندند؛ روی Nginx خودتان این مسیرها را مسدود کنید.


## تغییرات نسخهٔ ویرایش‌شده
- دکمهٔ اشتراک‌گذاری زیر عنوان و پنجرهٔ دیالوگ با آیکون‌های تک‌رنگ.
- تصویر شاخص نوشته از فرم مدیریت بارگذاری می‌شود و در فهرست نوشته‌ها در سمت چپ نمایش داده می‌شود.
- ویرایشگر Markdown برای بولد، ایتالیک، زیرخط، روخط، فهرست‌ها، نقل‌قول، کد و درج تصویر با عرض دلخواه.
- فیلدهای وضعیت، برچسب و دسته در یک ردیف قرار گرفته‌اند.
- هنگام نصب روی هاست، پوشهٔ `uploads` باید قابل نوشتن توسط PHP باشد. فایل `.htaccess` داخل آن اجرای فایل‌های PHP را مسدود می‌کند.
- تصاویر شاخص تا ۵ مگابایت و در قالب JPG، PNG، GIF یا WebP پذیرفته می‌شوند.

### تغییرات تکمیلی
- تصویر شاخص نوشته‌های صفحهٔ اول با نسبت ثابت ۴:۳ و اندازهٔ متناسب در کنار متن نمایش داده می‌شود.
- دکمهٔ اشتراک‌گذاری در همان ردیف دسته، زمان مطالعه و تاریخ قرار دارد.
- پنل مدیریت دارای Navigation Drawer واکنش‌گرا است و لینک پروفایل مدیر و تغییر رمز در آن قرار گرفته‌اند.
- صفحهٔ پروفایل امکان ویرایش نام، نام خانوادگی، تصویر، توضیح کوتاه و لینک شبکه‌های اجتماعی را دارد؛ تعداد نوشته‌های منتشرشده خودکار محاسبه می‌شود.
- تصویر مدیر در نوار بالایی و کنار گزینهٔ خروج نمایش داده می‌شود. اطلاعات پروفایل در `data/profile.json` ذخیره می‌شود.

### بنر سایت
از منوی مدیریت، گزینهٔ «بنر سایت» را باز کنید تا تصویر بنر را تغییر دهید. تصویر پیش‌فرض `uploads/site-banner.jpg` است. در صفحهٔ هر نوشته، تصویر شاخص همان نوشته به‌عنوان بنر نمایش داده می‌شود؛ اگر تصویر شاخص وجود نداشته باشد، بنر پیش‌فرض نمایش داده خواهد شد.
